One chat for all your coding agents.

Clanker Controller puts Claude Code, Codex, Antigravity and GitHub Copilot in one IDE window. You pick a model per message. It drives the CLIs you already have, so your sign-ins and flat-rate plans stay as they are.

01Features

Use every agent where you already work

Every agent in one place

One conversation can go from Claude to Codex to Gemini. Each agent gets a short briefing of what the others did, with a pointer to the full transcript.

Usage you can read at a glance

Each provider gets a ring with the percentage left in its 5-hour window and the time until it resets.

Your setup stays yours

Clanker uses your own CLI sign-ins and plans. It needs no API key for the coding agents and never bills you.

And more

Voice dictation with a personal dictionary, one project root per chat, loops for unattended review runs, and a Telegram link for checking in from your phone. It runs in VS Code and Antigravity IDE.

02Scheduler

A scheduler that works while you sleep

Hit a usage limit at 2 a.m.? The next prompt waits for the reset and runs by itself, in the same chat, model and project.

You can also schedule any prompt for a clock time, queue it behind the running task and reorder the queue by dragging.

The IDE has to stay open for scheduled prompts to run.

04Install

Install

Install from VS Code Marketplace Install from Open VSX
  • Windows 10 or 11. Linux and macOS are untested.
  • VS Code or Antigravity IDE.
  • At least one CLI: Claude Code, Codex, Antigravity or GitHub Copilot.

Or build it from source:

$ git clone https://github.com/Alexander-Ettl/Clanker-Controller.git
$ cd Clanker-Controller
$ npm install
$ node scripts/install-extension.mjs
