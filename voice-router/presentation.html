Voice-to-LLM Quota Router

A 315-millisecond background pipeline that captures developer voice, enriches it with active workspace context, checks live token headroom, and routes to the optimal AI model.

STEP 1 Voice Ingestion (OpenWhispr / Groq)
~120 ms
Developer presses hotkey or clicks [ ✨ Ask AI ]. Speech is recorded and immediately converted to raw text via Whisper-large-v3-turbo on Groq LPUs.
📂 Workspace Context < 3 ms
Reads currently open file path (e.g. site/src/layouts/Screen.astro), active cursor line, and current Git branch.
📊 Live Token Headroom < 2 ms
Synchronously reads VS Code status bar caches (Claude 5h window, Codex session rate limits, Gemini availability).
STEP 3 Single-Pass Decision Engine (GPT-OSS 120B / Jev)
~180 ms
Takes raw spoken text + local file context + live token quotas in a single fast prompt. It cleans stutters/disfluencies into formatted Markdown while simultaneously outputting the optimal model routing decision.

< 10 ms
The cleaned Markdown prompt and injected file context land directly on the system clipboard or trigger the active agent CLI automatically. Total turnaround: 315 ms (perceptually instantaneous).
